同行記錄的 JSON 格式

WhatsApp 可匯入一般客戶或同行私訊。其他渠道只收同行私訊。kind 可填 incoming（收到）、outgoing（已發出）或 found（已收藏的私訊線索）。

 "occurredAt":"2026-11-24T10:30:00+08:00"}]}
